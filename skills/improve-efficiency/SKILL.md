description: Update the agent docs with general context that would have made the current session faster or more efficient. Triggered by the user.

Analyse the current session: where did you waste the most time and tokens? What general project or codebase information would have made you faster or more token efficient? Focus on reusable context, not task-specific details from this session.

- Give your answer first; only then check the existing documentation and update it.
- First update GLOSSARY.md.
- Then update the documentation skills in .skills/docs.

You can create, split, or merge documentation files as you think is best; just don't make them too small. You can also update trigger conditions if a skill that was useless for the task was triggered, or if a skill that would have been useful was not triggered. Remove or update outdated or misleading information from the triggered skills. Don't assume you know better than the existing docs; verify your knowledge before updating them if you're not entirely confident.
